# TAXI SOFIA — тестово копие

Тестова версия за споделяне. Идентична на работещия сайт, но с **дистанционен ключ**.

## Как да я заключиш

Отвори `access.json` и смени:

```json
{ "enabled": false, "message": "Тестовият период приключи." }
```

Готово. До 10 минути (или веднага щом някой върне приложението на преден план)
всички получават заключен екран, а офлайн кешът и service worker-ът им се изтриват —
включително при инсталираните на телефона копия.

За отключване: върни `"enabled": true`.

## Какво НЕ прави ключът
Ако устройството няма никаква мрежа, приложението продължава да работи от паметта си
до първото свързване. Пълна забрана може да се постигне само със сървърна проверка.
